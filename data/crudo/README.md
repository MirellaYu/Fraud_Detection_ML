# Dataset original

El dataset original utilizado en este proyecto corresponde a:

**Fraud Detection Dataset**  
Autor: Aman Ali Siddiqui  
Fuente: Kaggle

## Fuente

📊 **[Descargar dataset original desde Kaggle](https://www.kaggle.com/datasets/amanalisiddiqui/fraud-detection-dataset?resource=download)**

## Descripción

El dataset contiene más de 6.3 millones de transacciones financieras y se utiliza para desarrollar un modelo de Machine Learning orientado a la detección de transacciones fraudulentas.

## Uso en el proyecto

Este dataset constituye la fuente de datos inicial para el proceso de:

1. Exploración y análisis de datos.
2. Selección de variables.
3. Preparación del dataset.
4. Entrenamiento de los modelos de Machine Learning.

Debido al tamaño del archivo, el dataset original no se almacena directamente en este repositorio.
